## 1. Yêu cầu nghiệp vụ

Admin quản lý toàn bộ nội dung học tập hệ thống: khoá học HSK, bài học, từ vựng, ngữ pháp, chủ đề và câu hỏi Public.

### 1.1. Phạm vi quản lý

| Loại nội dung | Thao tác |
| :--- | :--- |
| Khoá học (HSK Level) | Tạo, sửa tên/mô tả, bật/tắt |
| Bài học (Lesson) | Tạo, sửa, sắp xếp thứ tự, xuất bản/ẩn |
| Từ vựng (Vocabulary) | Tạo, sửa, xóa mềm, import CSV |
| Ngữ pháp (Grammar) | Tạo, sửa, xóa mềm |
| Chủ đề (Topic) | Tạo, sửa, gán từ vựng, bật/tắt |
| Câu hỏi Public | Tạo, sửa, xóa mềm |

### 1.2. Luồng quản lý từ vựng

1. Admin vào "Quản lý nội dung" → tab "Từ vựng".
2. Filter theo cấp HSK, bài học.
3. Tạo mới: Nhập Chữ Hán, Pinyin, Âm Hán Việt, Nghĩa tiếng Việt, Từ loại, Ví dụ câu.
4. Upload audio phát âm (file audio upload lên S3).
5. Sửa: Inline edit hoặc mở form chi tiết.
6. Xóa mềm: Đánh dấu `is_active = false`, không hiển thị cho học viên.
7. **Import CSV**: Upload file CSV theo template chuẩn → Backend parse và tạo hàng loạt.

### 1.3. Luồng xuất bản nội dung

* Nội dung mới tạo mặc định `status = DRAFT`.
* Admin review xong → bấm "Xuất bản" → `status = PUBLISHED`.
* Chỉ nội dung `PUBLISHED` mới hiển thị cho học viên.
* Admin có thể "Ẩn" nội dung đã xuất bản → `status = HIDDEN` (không xóa, chỉ ẩn).

### 1.4. Quy tắc chính

* Xóa mềm (soft delete) tất cả nội dung — không xóa vật lý.
* Nội dung đang được tham chiếu (VD: từ vựng trong bài tập đã có submission) → cảnh báo trước khi ẩn.
* Import CSV validate từng dòng, skip dòng lỗi và báo cáo.
* Mọi thao tác ghi audit log (PR-27).

### 3.2. Import CSV

**Template CSV từ vựng:**
```csv
hanzi,pinyin,han_viet,meaning_vi,word_type,example_sentence,hsk_level,lesson_order
你好,nǐ hǎo,Nễ hảo,Xin chào,Thán từ,你好，我是小明。,1,1
```

**Logic xử lý:**
1. Parse CSV, validate từng dòng.
2. Bỏ qua dòng có lỗi, ghi nhận vào báo cáo.
3. Tạo hàng loạt (bulk insert).
4. Trả response: `{ created: 45, skipped: 3, errors: [{line: 12, reason: "Missing pinyin"}] }`.

### 3.3. Xử lý lỗi

* Xóa nội dung đang được tham chiếu: `CONTENT_IN_USE` + danh sách nơi sử dụng.
* CSV sai format: `INVALID_CSV_FORMAT`.
* File audio sai định dạng: `INVALID_AUDIO_FORMAT`.

* Tab layout cho các loại nội dung.

* Nút audio: Play inline để nghe thử trước khi lưu.
