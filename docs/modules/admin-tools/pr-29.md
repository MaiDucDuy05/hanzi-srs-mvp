## 1. Yêu cầu nghiệp vụ

Admin xem, ẩn hoặc xóa nội dung vi phạm do giáo viên đăng. Admin **không** tự ý sửa nội dung chuyên môn.

### 1.1. Phạm vi quản lý

| Loại nội dung giáo viên | Quyền Admin |
| :--- | :--- |
| Câu hỏi Private | Xem, Ẩn, Xóa mềm |
| Bài đăng trong lớp | Xem, Ẩn, Xóa mềm |
| Bài kiểm tra | Xem, Ẩn |
| Tài liệu upload | Xem, Ẩn, Xóa mềm |

> **Nguyên tắc:** Admin KHÔNG có quyền Edit (sửa nội dung) tài liệu và câu hỏi của giáo viên. Điều này bảo vệ tính chuyên môn và trách nhiệm sở hữu nội dung.

### 1.2. Luồng xử lý vi phạm

1. Admin vào "Nội dung giáo viên" → Duyệt theo loại hoặc search.
2. Phát hiện nội dung vi phạm (sai nội dung, không phù hợp, spam...).
3. Bấm "Ẩn" → Popup nhập lý do (bắt buộc).
4. Nội dung bị ẩn:
   - Không hiển thị cho học sinh.
   - Giáo viên vẫn thấy nội dung nhưng có badge "Đã bị ẩn bởi Admin" + lý do.
   - Giáo viên có thể sửa và gửi yêu cầu "Mở lại" (appeal).
5. Admin xem lại nội dung đã sửa → "Mở lại" hoặc "Giữ ẩn".

### 1.3. Quy tắc chính

* Chỉ ẩn/xóa, không sửa nội dung giáo viên.
* Lý do ẩn bắt buộc (để giáo viên biết cần sửa gì).
* Giáo viên nhận thông báo khi nội dung bị ẩn.
* Ghi audit log (PR-27).

## 2. Triển khai Backend — NestJS

### 2.1. API cần triển khai

| Method | Endpoint | Chức năng |
| :--- | :--- | :--- |
| GET | `/api/admin/teacher-content` | Danh sách nội dung GV (filter loại, GV, trạng thái) |
| GET | `/api/admin/teacher-content/:type/:id` | Chi tiết nội dung |
| POST | `/api/admin/teacher-content/:type/:id/hide` | Ẩn nội dung + lý do |
| POST | `/api/admin/teacher-content/:type/:id/unhide` | Mở lại nội dung |

### 2.2. Thêm cột cho nội dung giáo viên

Các bảng `questions`, `classroom_posts`, `exams`, `resources` cần thêm:

| Cột | Kiểu | Mô tả |
| :--- | :--- | :--- |
| `hidden_by_admin` | BOOLEAN, default false | Bị admin ẩn |
| `hide_reason` | TEXT, nullable | Lý do ẩn |
| `hidden_at` | TIMESTAMP, nullable | Thời điểm ẩn |

## 4. Tiêu chí hoàn thành

PR-29 được nghiệm thu khi:

* Admin xem được tất cả nội dung do giáo viên tạo.
* Admin ẩn nội dung thành công kèm lý do.
* Nội dung bị ẩn không hiển thị cho học sinh.
* Giáo viên thấy badge "Bị ẩn" + lý do trên nội dung của mình.
* Admin không có nút Edit nội dung giáo viên.
* Ghi audit log đầy đủ.
