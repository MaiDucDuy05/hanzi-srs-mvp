## 1. Yêu cầu nghiệp vụ

Admin cấu hình các tham số hệ thống mà không cần deploy lại code.

### 1.1. Danh sách cấu hình

| Key | Kiểu | Mô tả | Mặc định |
| :--- | :--- | :--- | :--- |
| `free_attempt_limit` | INT | Số lượt luyện tập miễn phí/bài/ngày | 3 |
| `free_limit_reset_time` | TIME | Giờ reset lượt (timezone server) | 00:00 |
| `max_students_per_class` | INT | Giới hạn sĩ số lớp | 50 |
| `ai_provider` | ENUM | Provider AI đang dùng (openai/gemini) | openai |
| `ai_story_rate_limit_vip` | INT | Số lần tạo AI story/ngày cho VIP | 10 |
| `ai_story_rate_limit_teacher` | INT | Số lần tạo AI story/ngày cho Teacher | 30 |
| `ai_learning_path_rate_limit` | INT | Số lần gợi ý lộ trình/ngày cho Teacher | 5 |
| `vip_price_monthly` | INT | Giá gói VIP tháng (VNĐ) | 99000 |
| `vip_price_semi_annual` | INT | Giá gói VIP 6 tháng (VNĐ) | 499000 |
| `vip_price_annual` | INT | Giá gói VIP năm (VNĐ) | 899000 |
| `resource_max_file_size_mb` | INT | Dung lượng upload tối đa (MB) | 50 |
| `hskk_max_audio_size_mb` | INT | Dung lượng audio HSKK tối đa (MB) | 10 |
| `contact_email` | STRING | Email nhận thông báo lead | admin@xxx.com |
| `maintenance_mode` | BOOLEAN | Bật/tắt chế độ bảo trì | false |
| `feature_ai_enabled` | BOOLEAN | Bật/tắt tính năng AI | true |
| `feature_hskk_enabled` | BOOLEAN | Bật/tắt tính năng HSKK | true |

### 1.2. Luồng cấu hình

1. Admin vào "Cài đặt hệ thống".
2. Giao diện chia thành các nhóm (section):
   - **Giới hạn & Lượt chơi**: free_attempt_limit, free_limit_reset_time, max_students_per_class.
   - **AI**: ai_provider, rate limits.
   - **Thương mại**: Giá VIP, dung lượng upload.
   - **Feature Flags**: Bật/tắt tính năng.
   - **Hệ thống**: maintenance_mode, contact_email.
3. Sửa giá trị → Bấm "Lưu".
4. Hệ thống cập nhật DB + invalidate cache Redis.
5. Các service đọc config từ cache (không query DB mỗi request).

### 1.3. Quy tắc chính

* Thay đổi cấu hình có hiệu lực ngay lập tức (sau khi cache invalidate).
* Ghi audit log cho mỗi thay đổi.
* `maintenance_mode = true`: Tất cả API trả 503, chỉ Admin vào được.
* Validation: Giá VIP phải > 0, rate limit phải > 0, file size phải trong khoảng hợp lý.

Các service khác (PracticeService, AiService, SubscriptionService...) inject `ConfigCacheService` để đọc config thay vì hardcode.

### 3.4. Maintenance Mode Middleware

```typescript
@Injectable()
export class MaintenanceMiddleware implements NestMiddleware {
  async use(req, res, next) {
    const maintenance = await this.configCache.get('maintenance_mode');
    if (maintenance && !req.user?.role === 'ADMIN') {
      throw new ServiceUnavailableException('Hệ thống đang bảo trì.');
    }
    next();
  }
}
```

## 4. Triển khai Frontend — NextJS

| Route/Component | Vai trò |
| :--- | :--- |
| `/admin/settings` | Trang cấu hình hệ thống |

### 4.1. Cách xử lý giao diện

* Chia thành các section collapse/expand.
* Input render động: INT → number input, BOOLEAN → toggle switch, ENUM → select dropdown.
* Nút "Lưu" ở cuối mỗi section hoặc "Lưu tất cả" ở cuối trang.
* Hiển thị "Cập nhật lần cuối bởi {admin} lúc {time}" cho mỗi config.

## 6. Tiêu chí hoàn thành

PR-31 được nghiệm thu khi:

* Admin xem và sửa được tất cả config qua giao diện web.
* Thay đổi config có hiệu lực ngay (cache invalidate).
* Maintenance mode chặn tất cả API (trừ Admin).
* Feature flags bật/tắt được tính năng AI, HSKK.
* Giá VIP thay đổi phản ánh trên trang Pricing.
* Giới hạn lượt Free thay đổi phản ánh trong PracticeService.
* Audit log ghi đầy đủ.
