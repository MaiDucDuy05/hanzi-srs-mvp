## 1. Yêu cầu nghiệp vụ

Admin xem danh sách yêu cầu nâng cấp VIP, kích hoạt, gia hạn hoặc huỷ trạng thái VIP thủ công.

> **Lưu ý:** Logic kích hoạt/từ chối đã mô tả chi tiết trong PR-26. PR-30 tập trung vào **giao diện quản trị** và **các tác vụ bổ sung** mà Admin cần.

### 1.1. Luồng quản lý

1. Admin vào Dashboard → tab "Yêu cầu VIP".
2. Bảng danh sách:
   - Cột: User, Email, Gói (Tháng/6 Tháng/Năm), Số tiền, Nội dung CK, Ngày gửi, Trạng thái.
   - Filter: Theo trạng thái (`PENDING_PAYMENT`, `ACTIVE`, `REJECTED`, `EXPIRED`).
   - Sort: Mới nhất trước.
3. Với yêu cầu `PENDING_PAYMENT`:
   - Bấm "Kích hoạt" → Xác nhận → Hệ thống xử lý (PR-26 logic).
   - Bấm "Từ chối" → Nhập lý do → Gửi email cho user.
4. Với user đang VIP:
   - Bấm "Gia hạn thủ công" → Nhập số ngày thêm → Cộng dồn `vip_valid_until`.
   - Bấm "Hủy VIP" → Xác nhận → Chuyển role về FREE, clear `vip_valid_until`.

### 1.2. Dashboard tổng quan VIP

* Tổng số VIP hiện tại.
* Số yêu cầu đang chờ duyệt (badge đỏ).
* Doanh thu VIP tháng này (tổng `amount` của subscription `ACTIVE` trong tháng).
* Danh sách VIP sắp hết hạn (trong 7 ngày tới).

### 1.3. Quy tắc chính

* Tất cả thao tác ghi audit log.
* Gia hạn thủ công phải nhập lý do (VD: "Khuyến mãi", "Bồi thường lỗi hệ thống").
* Email tự động gửi khi: Kích hoạt, Từ chối, Hủy VIP, Gia hạn.

## 2. Triển khai Backend — NestJS

### 2.1. API cần triển khai

| Method | Endpoint | Chức năng |
| :--- | :--- | :--- |
| GET | `/api/admin/subscriptions` | Danh sách yêu cầu (filter, pagination) |
| GET | `/api/admin/subscriptions/stats` | Thống kê VIP (tổng, pending, doanh thu, sắp hết hạn) |
| PUT | `/api/admin/subscriptions/:id/approve` | Kích hoạt gói |
| PUT | `/api/admin/subscriptions/:id/reject` | Từ chối |
| POST | `/api/admin/subscriptions/:userId/extend` | Gia hạn thủ công |
| POST | `/api/admin/subscriptions/:userId/cancel` | Hủy VIP |

### 2.2. Response mẫu — Stats

```json
{
  "total_active_vip": 42,
  "pending_requests": 3,
  "revenue_this_month": 12500000,
  "expiring_soon": [
    { "user_id": "...", "name": "Nguyễn A", "expires_at": "2026-08-15" }
  ]
}
```

## 3. Triển khai Frontend — NextJS

| Route/Component | Vai trò |
| :--- | :--- |
| `/admin/subscriptions` | Trang quản lý VIP |
| `VipStatsCards` | 4 card thống kê (Total, Pending, Revenue, Expiring) |
| `SubscriptionTable` | Bảng yêu cầu |
| `ApproveModal` | Modal xác nhận kích hoạt |
| `RejectModal` | Modal nhập lý do từ chối |
| `ExtendModal` | Modal gia hạn (nhập số ngày + lý do) |

## 4. Tiêu chí hoàn thành

PR-30 được nghiệm thu khi:

* Admin xem được danh sách yêu cầu VIP với filter/sort.
* Kích hoạt VIP → role đổi thành VIP, email gửi cho user.
* Từ chối → email gửi lý do cho user.
* Gia hạn thủ công → cộng dồn thời hạn.
* Hủy VIP → role về FREE.
* Thống kê hiển thị đúng (tổng VIP, pending, doanh thu, sắp hết hạn).
* Audit log ghi đầy đủ.
