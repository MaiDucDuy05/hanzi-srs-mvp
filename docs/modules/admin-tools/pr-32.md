## 1. Yêu cầu nghiệp vụ

Admin xem tổng quan hệ thống: số người dùng, lượt luyện tập, doanh thu, lỗi hệ thống và tình trạng các tác vụ nền.

### 1.1. Nội dung Dashboard

**Row 1 — Thẻ thống kê nhanh (Summary Cards):**

| Thẻ | Dữ liệu | So sánh |
| :--- | :--- | :--- |
| Tổng người dùng | Count users | +X% so với tháng trước |
| VIP đang hoạt động | Count users có role VIP | +X so với tháng trước |
| Lượt luyện tập hôm nay | Count practice_attempts + exam_attempts ngày hôm nay | So với hôm qua |
| Doanh thu tháng này | Sum(amount) của vip_subscriptions ACTIVE tháng này | So với tháng trước |

**Row 2 — Biểu đồ:**

| Biểu đồ | Kiểu | Dữ liệu |
| :--- | :--- | :--- |
| Đăng ký mới theo ngày | Line chart | Count users group by ngày (30 ngày gần nhất) |
| Lượt luyện tập theo ngày | Bar chart | Count attempts group by ngày (30 ngày gần nhất) |

**Row 3 — Danh sách:**

| Danh sách | Nội dung |
| :--- | :--- |
| Yêu cầu VIP chờ duyệt | Top 5 request PENDING mới nhất (link sang PR-30) |
| VIP sắp hết hạn | Top 5 user hết hạn trong 7 ngày tới |
| Liên hệ chưa xử lý | Top 5 lead status NEW (link sang PR-25) |
| Lỗi hệ thống gần đây | Top 5 error log gần nhất (nếu có) |

**Row 4 — Tình trạng hệ thống:**

| Mục | Dữ liệu |
| :--- | :--- |
| Số lần gọi AI hôm nay | Count ai_usage_logs ngày hôm nay |
| Trạng thái cron jobs | Tên job + lần chạy cuối + status (OK/ERROR) |
| Dung lượng S3 đã dùng | Tổng dung lượng file (ước tính từ DB) |

### 1.2. Quy tắc chính

* Dashboard load data server-side (SSR) hoặc client-side với skeleton loading.
* Dữ liệu thống kê cache 5 phút (không cần real-time chính xác tuyệt đối).
* Click vào mỗi card/danh sách → Navigate sang trang quản lý chi tiết tương ứng.

## 2. Triển khai Backend — NestJS

### 2.1. API cần triển khai

| Method | Endpoint | Chức năng |
| :--- | :--- | :--- |
| GET | `/api/admin/dashboard/summary` | 4 thẻ thống kê nhanh |
| GET | `/api/admin/dashboard/charts` | Dữ liệu biểu đồ (30 ngày) |
| GET | `/api/admin/dashboard/pending-items` | Danh sách chờ xử lý |
| GET | `/api/admin/dashboard/system-health` | Tình trạng hệ thống |

### 2.2. Response mẫu — Summary

```json
{
  "total_users": { "value": 1250, "change_percent": 12.5 },
  "active_vip": { "value": 42, "change": 5 },
  "today_attempts": { "value": 328, "yesterday": 290 },
  "monthly_revenue": { "value": 12500000, "last_month": 10200000 }
}
```

### 2.3. Response mẫu — System Health

```json
{
  "ai_calls_today": 45,
  "cron_jobs": [
    { "name": "VIP Expiry Check", "last_run": "2026-08-12T00:00:00Z", "status": "OK" },
    { "name": "Vocab Schedule", "last_run": "2026-08-12T08:00:00Z", "status": "OK" }
  ],
  "storage_used_mb": 2450
}
```

### 2.4. Caching

* Tất cả endpoint dashboard cache 5 phút trong Redis.
* Cache key: `admin:dashboard:{endpoint}`.
* Invalidate khi có thao tác admin (approve VIP, ban user...).

## 3. Triển khai Frontend — NextJS

### 3.1. Route và thành phần

| Route/Component | Vai trò |
| :--- | :--- |
| `/admin` hoặc `/admin/dashboard` | Trang dashboard chính |
| `SummaryCard` | Card thống kê (icon, số lớn, so sánh %) |
| `RegistrationChart` | Line chart đăng ký mới |
| `AttemptsChart` | Bar chart lượt luyện tập |
| `PendingList` | Danh sách chờ xử lý (clickable) |
| `SystemHealth` | Bảng tình trạng hệ thống |

### 3.2. Cách xử lý giao diện

* Layout grid responsive: 4 card trên 1 hàng (desktop), 2 card (tablet), 1 card (mobile).
* Card summary: Icon bên trái, số liệu lớn bên phải, badge xanh/đỏ cho % thay đổi.
* Biểu đồ: Dùng Recharts hoặc Chart.js. Tooltip khi hover.
* Danh sách chờ: Mỗi item clickable, navigate sang trang quản lý tương ứng.
* Auto-refresh data mỗi 5 phút (polling hoặc SWR revalidation).

## 4. Thứ tự triển khai cho đội nhỏ

1. API summary (aggregate queries).
2. API charts (group by date).
3. API pending items (simple queries).
4. API system health.
5. Frontend: Summary cards.
6. Frontend: Charts (Recharts).
7. Frontend: Pending lists + System health.
8. Caching + auto-refresh.

## 5. Tiêu chí hoàn thành

PR-32 được nghiệm thu khi:

* Dashboard hiển thị đủ 4 thẻ thống kê với so sánh.
* Biểu đồ đăng ký và lượt luyện tập render 30 ngày gần nhất.
* Danh sách chờ xử lý (VIP pending, liên hệ, VIP sắp hết hạn) hiển thị và clickable.
* Tình trạng hệ thống (AI calls, cron jobs, storage) hiển thị.
* Dữ liệu cache 5 phút, không gây tải DB.
* Responsive trên desktop, tablet, mobile.
