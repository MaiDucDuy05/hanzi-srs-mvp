## 1. Yêu cầu nghiệp vụ

Giáo viên nhận gợi ý nội dung buổi học tiếp theo dựa trên dữ liệu tổng hợp của cả lớp.

### 1.1. Luồng chính

1. Giáo viên vào trang lớp → tab "Đề xuất bài học".
2. Hệ thống phân tích tự động:
   - Câu hỏi nào lớp làm sai nhiều nhất (top 10).
   - Kỹ năng nào yếu nhất (Nghe, Đọc, Viết, Ngữ pháp).
   - Bài học nào nhiều học sinh chưa hoàn thành.
3. Hiển thị gợi ý dạng danh sách card:
   - **"Ôn lại Ngữ pháp HSK3 — Bài 5"**: 8/15 học sinh sai câu hỏi liên quan.
   - **"Tập trung luyện Nghe"**: Điểm trung bình kỹ năng Nghe thấp nhất lớp.
   - **"Bài luyện tập chưa hoàn thành"**: 6 học sinh chưa làm bài X.
4. Giáo viên click vào gợi ý → có thể tạo nhanh bài đăng (PR-07) hoặc bài kiểm tra (PR-05) từ gợi ý.

### 1.2. Quy tắc chính

* Dữ liệu gợi ý lấy từ 30 ngày gần nhất.
* Không dùng AI cho v1 (chỉ tính toán thống kê). AI gợi ý text mô tả là nice-to-have.
* Tối thiểu 5 học sinh có dữ liệu mới hiển thị gợi ý (tránh bias khi lớp quá ít người).

## 2. Thiết kế dữ liệu

Không cần bảng mới. Truy vấn aggregation từ:
* `exam_attempts` → tỷ lệ đúng/sai theo câu hỏi.
* `practice_attempts` → điểm theo loại kỹ năng.
* `post_completions` → bài chưa hoàn thành.

## 3. Triển khai Backend — NestJS

### 3.1. API cần triển khai

| Method | Endpoint | Actor | Chức năng |
| :--- | :--- | :--- | :--- |
| GET | `/api/classrooms/:id/insights` | Teacher | Lấy gợi ý bài học cho lớp |

**Response:**
```json
{
  "weakest_skills": [
    { "skill": "listening", "avg_score": 45.2 }
  ],
  "most_failed_questions": [
    { "question_id": "...", "question_text": "...", "fail_rate": 0.73 }
  ],
  "incomplete_posts": [
    { "post_id": "...", "title": "...", "incomplete_count": 6, "total_students": 15 }
  ],
  "suggested_lessons": [
    { "lesson_id": "...", "lesson_title": "HSK3 Bài 5", "reason": "8/15 học sinh sai câu ngữ pháp liên quan" }
  ]
}
```

### 3.2. Logic tính toán

* **Kỹ năng yếu:** Group `practice_attempts` theo `practiceType`, tính `AVG(score)` mỗi loại, sắp xếp tăng dần.
* **Câu sai nhiều:** Từ `exam_attempts.answers`, đếm `fail_count` mỗi `question_id`, lọc `fail_rate > 0.5`.
* **Bài chưa hoàn thành:** Left join `classroom_posts` với `post_completions`, đếm số học sinh chưa complete.

## 4. Tiêu chí hoàn thành

PR-21 được nghiệm thu khi:

* Giáo viên xem được danh sách gợi ý dựa trên dữ liệu thực.
* Gợi ý hiển thị kỹ năng yếu nhất, câu hỏi sai nhiều nhất, bài chưa hoàn thành.
* Không hiển thị gợi ý khi lớp có ít hơn 5 học sinh có dữ liệu.
* Click vào gợi ý có thể chuyển sang tạo bài đăng hoặc bài kiểm tra.
