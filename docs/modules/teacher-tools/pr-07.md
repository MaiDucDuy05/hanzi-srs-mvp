## 1. Yêu cầu nghiệp vụ

Giáo viên đăng nội dung, tài liệu hoặc bài luyện tập cho lớp. Cấu hình thời gian mở và hạn hoàn thành.

### 1.1. Luồng giáo viên đăng bài

1. Giáo viên vào trang quản lý lớp → tab "Bài đăng".
2. Bấm "Tạo bài đăng mới".
3. Chọn loại bài đăng:
   - **Bài học**: Gắn link tới bài học có sẵn trong hệ thống (Lesson từ FR-01).
   - **Bài luyện tập**: Gắn link tới dạng luyện tập cụ thể (Flashcard, Nối từ, Điền từ...).
   - **Tài liệu**: Upload hoặc gắn link tới tài liệu PPT/PDF (từ FR-24).
   - **Thông báo**: Nội dung text thuần (VD: "Lớp nghỉ ngày mai").
4. Nhập tiêu đề, mô tả và hướng dẫn (rich text đơn giản).
5. Cấu hình:
   - `visible_from`: Ngày giờ bài đăng xuất hiện với học sinh.
   - `due_date` (optional): Hạn hoàn thành (áp dụng cho bài luyện tập).
   - `is_pinned`: Ghim bài lên đầu (tối đa 3 bài ghim/lớp).
6. Bấm "Đăng" → Bài hiển thị trên feed lớp học.

### 1.2. Luồng học sinh xem bài

1. Học sinh vào trang lớp học → tab "Bài đăng" (feed dạng timeline).
2. Bài mới nhất hiển thị trước, bài ghim luôn ở trên cùng.
3. Click vào bài → xem chi tiết và thực hiện (nếu là bài luyện tập).
4. Trạng thái hoàn thành: Hệ thống tự đánh dấu khi học sinh hoàn thành bài liên kết.

### 1.3. Quy tắc chính

* Giáo viên chỉ đăng bài vào lớp mình sở hữu.
* Bài đăng có `visible_from` trong tương lai sẽ không hiển thị cho học sinh.
* Giáo viên có thể sửa, ẩn hoặc xóa bài đăng bất kỳ lúc nào.
* Tối đa 3 bài ghim đồng thời. Ghim bài thứ 4 sẽ tự bỏ ghim bài ghim cũ nhất.

## 2. Thiết kế dữ liệu

### 2.1. Bảng `classroom_posts`

| Cột | Kiểu | Mô tả |
| :--- | :--- | :--- |
| `id` | UUID, PK | |
| `classroom_id` | UUID, FK → classrooms | Lớp |
| `teacher_id` | UUID, FK → users | Giáo viên đăng |
| `type` | ENUM(`LESSON`, `PRACTICE`, `RESOURCE`, `ANNOUNCEMENT`) | Loại bài đăng |
| `title` | VARCHAR(255) | Tiêu đề |

| `visible_from` | TIMESTAMP | Thời điểm hiển thị |

| `is_active` | BOOLEAN, default true | Ẩn/hiện |

## 3. Triển khai Backend — NestJS

### 3.1. API cần triển khai

| Method | Endpoint | Actor | Chức năng |
| :--- | :--- | :--- | :--- |
| POST | `/api/classrooms/:classId/posts` | Teacher | Tạo bài đăng |
| GET | `/api/classrooms/:classId/posts` | Teacher, Student | Danh sách bài (có filter, pagination) |
| GET | `/api/classrooms/:classId/posts/:id` | Teacher, Student | Chi tiết bài đăng |
| PUT | `/api/classrooms/:classId/posts/:id` | Teacher (owner) | Cập nhật |
| DELETE | `/api/classrooms/:classId/posts/:id` | Teacher (owner) | Xóa |
| POST | `/api/classrooms/:classId/posts/:id/complete` | Student | Đánh dấu hoàn thành |

**Lưu ý query:** Với Student, API trả về chỉ các bài có `visible_from <= now()` và `is_active = true`.

## 4. Triển khai Frontend — NextJS

| Route/Component | Vai trò |
| :--- | :--- |
| `/teacher/classrooms/[id]/posts` | Quản lý bài đăng của lớp |
| `/student/classrooms/[id]/feed` | Feed lớp học của học sinh |
| `PostCard` | Card hiển thị bài đăng (tiêu đề, loại, deadline, trạng thái) |
| `PostForm` | Form tạo/sửa bài đăng |

## 5. Tiêu chí hoàn thành

PR-07 được nghiệm thu khi:

* Giáo viên tạo được bài đăng ở 4 loại (Lesson, Practice, Resource, Announcement).
* Bài đăng hiển thị trên feed lớp học theo thứ tự thời gian, bài ghim trên cùng.
* Học sinh không thấy bài có `visible_from` trong tương lai.
* Trạng thái hoàn thành được cập nhật khi học sinh thực hiện xong bài liên kết.
* Giáo viên chỉ quản lý bài đăng của lớp mình.
