## 1. Yêu cầu nghiệp vụ

Giáo viên xem thống kê tổng quan và chi tiết từng học sinh trong lớp.

### 1.1. Tổng quan lớp (Class Overview)

1. **Bảng xếp hạng:** Danh sách học sinh sắp theo điểm trung bình (giảm dần).
2. **Tỷ lệ hoàn thành:** Bao nhiêu % học sinh đã hoàn thành bài được giao.
3. **Highlight cảnh báo:** Học sinh có điểm < 50% liên tiếp 2 bài → đánh dấu đỏ.
4. **Top câu hỏi sai:** Các câu hỏi có tỷ lệ sai > 50% trong lớp.

### 1.2. Chi tiết học sinh (Student Detail)

1. Giáo viên click vào tên học sinh → trang chi tiết.
2. Hiển thị:
   - Lịch sử làm bài (bài kiểm tra + luyện tập): Ngày, Điểm, Thời gian.
   - Biểu đồ xu hướng: Điểm theo thời gian (line chart).
   - Sổ lỗi sai hiện tại: Danh sách câu hỏi trong sổ lỗi sai.
   - Kỹ năng radar: Biểu đồ radar 4 trục (Nghe, Đọc, Viết, Ngữ pháp).

### 1.3. Quy tắc chính

* Giáo viên chỉ xem được dữ liệu học sinh trong lớp mình.
* Dữ liệu tính từ 30 ngày gần nhất (hoặc tùy chọn khoảng thời gian).
* Cảnh báo chỉ hiển thị khi có ít nhất 2 bài kiểm tra đã chấm.

## 2. Triển khai Backend — NestJS

### 2.1. API cần triển khai

| Method | Endpoint | Actor | Chức năng |
| :--- | :--- | :--- | :--- |
| GET | `/api/classrooms/:id/progress` | Teacher | Tổng quan tiến trình lớp |
| GET | `/api/classrooms/:id/progress/:studentId` | Teacher | Chi tiết 1 học sinh |
| GET | `/api/classrooms/:id/progress/failed-questions` | Teacher | Top câu hỏi sai |

### 2.2. Response mẫu — Tổng quan lớp

```json
{
  "total_students": 15,
  "completion_rate": 0.73,
  "leaderboard": [
    { "student_id": "...", "name": "Nguyễn Văn A", "avg_score": 85.5, "exams_completed": 8, "alert": false },
    { "student_id": "...", "name": "Trần Thị B", "avg_score": 42.0, "exams_completed": 6, "alert": true }

```

## 3. Triển khai Frontend — NextJS

| Route/Component | Vai trò |
| :--- | :--- |
| `/teacher/classrooms/[id]/progress` | Dashboard tiến trình lớp |
| `/teacher/classrooms/[id]/progress/[studentId]` | Chi tiết học sinh |
| `Leaderboard` | Bảng xếp hạng + badge cảnh báo |
| `ScoreTrendChart` | Line chart điểm theo thời gian |
| `SkillRadar` | Radar chart 4 kỹ năng |
| `FailedQuestionsList` | Danh sách câu sai nhiều |

## 4. Tiêu chí hoàn thành

PR-23 được nghiệm thu khi:

* Dashboard lớp hiển thị bảng xếp hạng, tỷ lệ hoàn thành, top câu sai.
* Badge cảnh báo hiển thị với học sinh yếu (2 bài liên tiếp < 50%).
* Drill-down vào học sinh hiển thị lịch sử, biểu đồ xu hướng, radar kỹ năng.
* Giáo viên chỉ xem được dữ liệu lớp mình.
