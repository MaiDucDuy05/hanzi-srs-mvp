## 1. Yêu cầu nghiệp vụ

Hệ thống tổ chức nội dung theo cấu trúc hai nhánh song song:

**Nhánh HSK:** Cấp HSK (1–9) → Bài học → Từ vựng & Ngữ pháp

**Nhánh Topic:** Chủ đề (slug) → Từ vựng

Người học thực hiện được:
* Xem danh sách cấp HSK 1–9 kèm số lượng từ vựng mỗi cấp.
* Xem danh sách bài học trong một cấp HSK, lọc và tìm kiếm.
* Mở bài học, xem từ vựng và ngữ pháp theo đúng thứ tự.
* Với mỗi từ vựng: xem chữ Hán, pinyin, nghĩa tiếng Việt, từ loại, câu ví dụ và nghe audio.
* Xem danh sách chủ đề (Topics), vào chi tiết chủ đề xem toàn bộ từ vựng.
* Luyện tập ngay từ trang chi tiết bài học hoặc chủ đề.

Admin thực hiện được:
* CRUD đầy đủ cho HSK Level, Lesson, Vocabulary, GrammarPoint, LessonContent, Topic, TopicVocabulary.
* Lưu nháp (`DRAFT`) hoặc xuất bản (`PUBLISHED`) bài học/từ vựng.
* Upload audio từ vựng (POST `/api/v1/audio/upload`).
* Sắp xếp thứ tự bài học và nội dung trong bài qua `displayOrder`.
* Xoá mềm bài học và từ vựng (trường `deletedAt`, không xoá cứng khỏi DB).

> **Giới hạn MVP:** Chưa có quy trình duyệt nhiều bước, audit log hay lịch sử phiên bản nội dung.

### 1.1. Quy tắc chính

* Mỗi bài học thuộc đúng một cấp HSK (`levelId`).
* Học viên chỉ xem được bài/từ vựng có trạng thái `PUBLISHED`.
* Mọi API ghi dữ liệu (POST/PATCH/DELETE) phải qua JWT Auth Guard và Role Guard (`ADMIN` hoặc `TEACHER`).
* Xoá bài/từ vựng dùng xoá mềm (`softRemove`) để không ảnh hưởng dữ liệu practice/SRS.
* Nội dung bài được tập hợp qua `lesson_contents` (polymorphic) — không join trực tiếp bảng entity.

## 2. Thiết kế dữ liệu — Bảng đã triển khai

Module `curriculum` gồm **8 bảng / entity**:

| Bảng | Entity file | Dữ liệu cốt lõi |
| :--- | :--- | :--- |
| `hsk_levels` | `hsk-level.entity.ts` | `code` (HSK1–9), `name`, `displayOrder` |
| `lessons` | `lesson.entity.ts` | `levelId`, `title`, `description`, `displayOrder`, `status`, `publishedAt`, `deletedAt` |
| `vocabularies` | `vocabulary.entity.ts` | `levelId`, `hanzi`, `pinyin`, `meaningVi`, `audioKey`, `partOfSpeech`, `example`, `status`, `deletedAt` |
| `grammar_points` | `grammar-point.entity.ts` | `levelId`, `title`, `structure`, `explanation`, `status`, `deletedAt` |
| `lesson_contents` | `lesson-content.entity.ts` | `lessonId`, `contentType` (`VOCABULARY`\|`GRAMMAR`), `contentId`, `displayOrder` |
| `topics` | `topic.entity.ts` | `name`, `slug`, `description`, `thumbnailKey`, `recommendedLevelId`, `status`, `displayOrder`, `deletedAt` |
| `topic_vocabularies` | `topic-vocabulary.entity.ts` | `topicId`, `vocabularyId`, `displayOrder` |
| `assignments` | `assignment.entity.ts` | `title`, `description`, `assignedBy`, `assignedTo`, `dueDate`, `status` |

**Lưu ý thiết kế:**
- Tất cả entity kế thừa `BaseEntity` (UUID PK, `createdAt`, `updatedAt`).
- `lesson_contents` dùng kiểu polymorphic: `contentType` xác định bảng nguồn, `contentId` là FK logic (không phải FK vật lý).
- `hsk_levels` không có `deletedAt` — không xoá mềm cấp HSK.
- `vocabularies` có thêm `partOfSpeech` và `example` ngoài đặc tả gốc.
- `topics` có thêm `slug` (URL-friendly), `thumbnailKey` và `recommendedLevelId`.

#### Audio

| Method | Endpoint | Chức năng |
| :--- | :--- | :--- |
| GET | `/audio/:key` | Phát audio theo `audioKey` (serve file tĩnh, `Cache-Control: public, max-age=300`). |
| POST | `/audio/upload` | Upload file audio (multipart/form-data, field `file`). Trả `{ audioKey }`. Giới hạn 10 MB. |

**Lưu ý audio:**
- MVP dùng thư mục cục bộ `AUDIO_STORAGE_DIR` (mặc định `./storage/audio`). Không dùng S3/presigned URL.
- Hỗ trợ: mp3, m4a, wav, ogg, webm, aac, flac.
- `audioKey` là UUID + extension phẳng, không chứa path separator.
- Frontend sau khi upload nhận `audioKey`, PATCH lên `/vocabularies/:id` để lưu.

### 3.3. Luồng lấy nội dung bài học

```
GET /lessons/:id/contents
  → LessonService.getContents(lessonId)
  → Query lesson_contents WHERE lessonId ORDER BY displayOrder ASC
  → Tách vocabIds vs grammarIds
  → Promise.all([
      vocabRepo.find({ id: In(vocabIds) }),
      grammarRepo.find({ id: In(grammarIds) })
    ])
  → Response: { vocabularies[], grammarPoints[] }
```

Không N+1 — tổng hợp trong 3 query (1 contents + 2 batch find).

### 3.4. Phân quyền

- `JwtAuthGuard` bảo vệ tất cả route trong module.
- Chưa dùng `RolesGuard` riêng cho curriculum — Admin quản lý nội dung qua trang `/admin` riêng.
- Học viên (Free/VIP) chỉ thực hiện GET; POST/PATCH/DELETE qua giao diện Admin.

### 3.5. Hiệu năng

- `hsk-level.service.ts`: batch count `vocabularyCount` bằng một query GROUP BY thay vì N+1.
- `topic.service.ts`: tương tự batch count `vocabularyCount` cho từng topic.
- Index được tạo trong migration cho `lessons(level_id, status, display_order)`.

## 4. Triển khai Frontend — NextJS (App Router)

### 4.1. Cấu trúc routes đã triển khai

```text
app/(student)/
  dashboard/
    courses/
      page.tsx                        → CoursesFeature (danh sách HSK levels)
      hsk/
        page.tsx                      → CoursesFeature (same, alias route)
      [id]/
        page.tsx                      → CourseDetailFeature (bài học trong 1 level)
      topic/
        page.tsx                      → CoursesTopicFeature (danh sách topics)
        [slug]/
          page.tsx                    → TopicDetailFeature (từ vựng trong topic)
  study/
    [lessonId]/
      page.tsx                        → StudyLessonFeature (xem chi tiết bài + audio)
```

### 4.2. Features (Client Components)

| Feature | File | Chức năng |
| :--- | :--- | :--- |
| `CoursesFeature` | `features/dashboard/page-features/courses-feature.tsx` | Grid HSK levels, link vào `CourseDetailFeature`. |
| `CourseDetailFeature` | `features/dashboard/page-features/course-detail-feature.tsx` | Danh sách bài học, search, phân trang 25 bài/trang. |
| `CoursesTopicFeature` | `features/courses/courses-topic-feature.tsx` | Grid topics theo gradient màu. Click → `TopicDetailFeature`. |
| `TopicDetailFeature` | `features/dashboard/page-features/topic-detail-feature.tsx` | Danh sách từ vựng của topic (Hán, pinyin, nghĩa, audio), search, phân trang 25 từ/trang. Nút "Luyện tập ngay" trỏ vào practice WORD_MATCHING. |
| `StudyLessonFeature` | `features/student/study-lesson-feature.tsx` | Xem chi tiết bài học, phát audio từ vựng qua `AudioButton`. |

### 4.3. API client

- Endpoint tập trung ở `lib/api/endpoints/curriculum.ts` (hàm `curriculumApi`).
- Dữ liệu HSK levels từ `GET /hsk-levels` trả kèm `vocabularyCount` (batch count từ backend).
- Nội dung bài học tải bằng `GET /lessons/:id/contents` → `{ vocabularies, grammarPoints }`.
- Topics dùng `GET /topics` + `GET /topic-vocabularies?topicId=...` + `GET /vocabularies/:id` (resolve per vocabulary).

### 4.4. Audio

- Component `AudioButton` (`features/ui/components/audio-button.tsx`) gọi `GET /audio/:key`.
- Hỗ trợ `Accept-Ranges` → có thể seek audio trên trình duyệt.
- Nếu `audioKey` là null → `AudioButton` không render hoặc hiển thị disabled.
