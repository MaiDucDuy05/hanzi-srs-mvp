## 1. Yêu cầu nghiệp vụ

Hiển thị dashboard cá nhân với biểu đồ và số liệu thống kê tiến trình học tập.

### 1.1. Nội dung dashboard

**1. Tiến độ tổng quan:**
* % bài học đã hoàn thành / tổng bài học của cấp HSK hiện tại.
* Số từ vựng đã học / tổng từ vựng cấp hiện tại.
* Chuỗi ngày học liên tiếp (Learning streak).

**2. Biểu đồ Radar kỹ năng (4 trục):**
* Từ vựng: Dựa trên điểm flashcard + nối từ.
* Ngữ pháp: Dựa trên điểm điền từ + sắp xếp câu.
* Nghe hiểu: Dựa trên điểm bài có audio.
* Đọc hiểu: Dựa trên điểm bài trắc nghiệm đọc.

**3. Biểu đồ xu hướng (Line chart):**
* Điểm trung bình theo tuần trong 3 tháng gần nhất.

**4. Hoạt động gần đây:**
* 10 bài tập/kiểm tra gần nhất: Loại, Điểm, Thời gian.

### 1.2. Quy tắc chính

* Mỗi user chỉ xem được stats của chính mình.
* Dữ liệu radar lấy từ 30 ngày gần nhất.
* Nếu một kỹ năng không có dữ liệu: Hiển thị 0 và ghi chú "Chưa có dữ liệu".
* Learning streak tính ngày có ít nhất 1 hoạt động (làm bài, xem flashcard).

## 2. Triển khai Backend — NestJS

### 2.1. API cần triển khai

| Method | Endpoint | Actor | Chức năng |
| :--- | :--- | :--- | :--- |
| GET | `/api/progress/overview` | Owner | Tiến độ tổng quan |
| GET | `/api/progress/skills` | Owner | Dữ liệu radar kỹ năng |
| GET | `/api/progress/trend` | Owner | Dữ liệu xu hướng điểm |
| GET | `/api/progress/recent-activities` | Owner | Hoạt động gần đây |

### 2.2. Response mẫu — Overview

```json
{
  "current_hsk_level": 3,
  "lessons_completed": 12,
  "lessons_total": 30,
  "vocab_learned": 145,
  "vocab_total": 600,
  "learning_streak_days": 7,
  "total_practice_time_minutes": 320,
  "mistake_book_count": 23
}
```

### 2.3. Response mẫu — Skills Radar

```json
{
  "period_days": 30,
  "skills": {
    "vocabulary": { "score": 72, "sample_count": 15 },
    "grammar": { "score": 65, "sample_count": 10 },
    "listening": { "score": 0, "sample_count": 0 },
    "reading": { "score": 58, "sample_count": 8 }
  }
}
```

### 2.4. Logic tính toán

* **Lessons completed:** Count từ bảng `lesson_progress` hoặc `post_completions` nơi lesson đã hoàn thành.
* **Vocab learned:** Count distinct `vocabulary_id` trong `practice_attempts` có kết quả đúng.
* **Learning streak:** Query `practice_attempts` + `exam_attempts` group by date DESC, đếm chuỗi ngày liên tiếp.
* **Skill scores:** Map `practiceType` → skill category, tính `AVG(score)`.

## 3. Triển khai Frontend — NextJS

| Route/Component | Vai trò |
| :--- | :--- |
| `/dashboard` hoặc `/progress` | Trang dashboard cá nhân |
| `ProgressOverview` | Card tiến độ (progress bar + số liệu) |
| `SkillRadar` | Biểu đồ radar (dùng Chart.js hoặc Recharts) |
| `ScoreTrend` | Line chart xu hướng |
| `RecentActivities` | Danh sách hoạt động gần đây |
| `StreakBadge` | Badge chuỗi ngày học |

### 3.1. Cách xử lý giao diện

* Dashboard bố trí dạng grid: Overview cards ở trên, Radar + Trend ở giữa, Activities ở dưới.
* Progress bar animate khi load lần đầu.
* Streak badge có hiệu ứng lửa 🔥 khi streak ≥ 7 ngày.
* Responsive: Trên mobile, xếp dọc.

## 4. Tiêu chí hoàn thành

PR-18 được nghiệm thu khi:

* Dashboard hiển thị đủ 4 phần: Overview, Radar, Trend, Activities.
* Tiến độ bài học và từ vựng tính đúng.
* Biểu đồ radar hiển thị 4 kỹ năng, ghi chú "Chưa có dữ liệu" nếu trống.
* Learning streak tính chính xác.
* Dữ liệu chỉ thuộc user hiện tại.
