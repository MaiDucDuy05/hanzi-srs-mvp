## 1. Nguồn dữ liệu và mã nguồn

| Nguồn | Cách sử dụng trong dự án |
| :--- | :--- |
| `hanzi-writer` | Thư viện JavaScript hiển thị, chạy animation và kiểm tra thứ tự nét. |
| `hanzi-writer-data` | JSON dữ liệu SVG và nét viết của từng chữ Hán. |
| `wenbun` | Tham khảo luồng luyện viết, quản lý phiên và cách tích hợp Hanzi Writer phía client. |

**Repository dữ liệu:** https://github.com/chanind/hanzi-writer-data

**Repository tham khảo:** https://github.com/ray-pH/wenbun

Wenbun sử dụng Svelte/Tauri trong khi hệ thống hiện tại dùng NextJS. Vì vậy không nhúng nguyên ứng dụng Wenbun. Đội dự án chỉ tham khảo luồng xử lý và port phần cần thiết thành React Client Component.

> **Phạm vi MVP:** Dùng cơ chế quiz có sẵn của Hanzi Writer để kiểm tra thứ tự và hướng nét. Đây là bài luyện tập có hướng dẫn, không phải AI nhận diện chữ viết tự do và không chấm độ đẹp của chữ.

## 2. Yêu cầu nghiệp vụ

Người học chọn một từ vựng hoặc bài học, sau đó luyện lần lượt từng chữ Hán trong từ.

Luồng người học:

1. Chọn cấp HSK, bài học hoặc từ vựng cần luyện.
2. Hệ thống tách từ thành từng chữ Hán.
3. Người học xem animation thứ tự nét của chữ hiện tại.
4. Người học chuyển sang chế độ luyện viết và vẽ từng nét trên khung chữ.
5. Hệ thống phản hồi ngay khi nét đúng hoặc sai; sau nhiều lần sai thì hiển thị gợi ý.
6. Khi hoàn thành chữ, chuyển sang chữ tiếp theo.
7. Cuối phiên, hiển thị số chữ hoàn thành, tổng số lỗi và thời gian luyện.

### 2.1. Quy tắc chính

* Chỉ luyện các ký tự có dữ liệu trong `hanzi-writer-data`.
* Mỗi phiên có hai chế độ: **Xem thứ tự nét** và **Tự viết**.
* Chế độ tự viết dùng quiz của Hanzi Writer với outline và gợi ý nét.
* Sau ba lần sai cùng một nét, hệ thống làm nổi bật nét đúng.
* Người học có thể xem lại animation hoặc làm lại chữ hiện tại.
* Kết quả chỉ ghi nhận hoàn thành và số lỗi; không quy đổi thành điểm thi.
* Free User áp dụng giới hạn lượt theo PR-14; VIP không giới hạn.

## 3. Cách cung cấp dữ liệu nét chữ

### 3.1. Phương án MVP

Sử dụng hai package `hanzi-writer` và `hanzi-writer-data`. Không tải file `all.json` vì kích thước lớn. Chỉ lấy các file JSON của những ký tự xuất hiện trong kho từ vựng HSK.

Quy trình chuẩn bị dữ liệu:

1. Lấy danh sách chữ Hán duy nhất từ dữ liệu FR-01.
2. Chạy script build để sao chép JSON tương ứng từ package `hanzi-writer-data`.
3. Upload các file lên S3 theo cấu trúc `hanzi-data/<character>.json`.
4. Phân phối qua CloudFront và cấu hình cache dài hạn.
5. Frontend dùng `charDataLoader` để tải đúng file của ký tự đang luyện.

Trong giai đoạn prototype có thể dùng loader CDN mặc định của Hanzi Writer. Trước khi production nên tự host dữ liệu đã chọn để chủ động hiệu năng và phiên bản.

### 3.2. Xử lý thiếu dữ liệu

Nếu file ký tự không tồn tại hoặc tải thất bại:

* Hiển thị thông báo "Chưa có dữ liệu nét viết cho chữ này".
* Cho phép bỏ qua và chuyển sang chữ tiếp theo.
* Ghi log ký tự thiếu để Admin bổ sung dữ liệu khi cập nhật kho từ.
* Không tính ký tự bị thiếu vào kết quả phiên luyện.

## 4. Triển khai Frontend -- NextJS

### 4.1. Cấu trúc component

```text
writing/
  HanziWriterCanvas.tsx
  WritingPractice.tsx
  CharacterNavigator.tsx
  PracticeToolbar.tsx
  WritingResult.tsx
```

| Component | Vai trò |
| :--- | :--- |
| `HanziWriterCanvas` | Khởi tạo, huỷ và điều khiển instance Hanzi Writer. |
| `WritingPractice` | Quản lý ký tự hiện tại, chế độ animation/quiz và kết quả phiên. |
| `CharacterNavigator` | Chuyển chữ trước/sau trong từ hoặc bài học. |
| `PracticeToolbar` | Xem mẫu, luyện lại, bật/tắt outline và gợi ý. |
| `WritingResult` | Tổng số chữ hoàn thành, lỗi và thời gian. |

### 4.2. Tích hợp Hanzi Writer

* Dùng dynamic import với SSR tắt vì Hanzi Writer cần DOM.
* Khởi tạo instance trong `useEffect` và lưu bằng `useRef`.
* Khi đổi ký tự, huỷ quiz cũ rồi gọi `setCharacter` hoặc tạo instance mới.
* Nút xem mẫu gọi `animateCharacter()`.
* Chế độ luyện gọi `quiz()` với callback `onMistake`, `onCorrectStroke` và `onComplete`.
* Callback chỉ cập nhật state phiên; cuối phiên mới gửi kết quả lên backend.
* Kích thước canvas thay đổi theo màn hình bằng `updateDimensions()`.

### 4.3. Route

| Route | Nội dung |
| :--- | :--- |
| `/practice/hanzi-writing` | Chọn cấp, bài hoặc từ vựng. |
| `/practice/hanzi-writing/[attemptId]` | Luyện viết và xem kết quả. |

Trên mobile web, vùng viết chiếm phần lớn chiều ngang; toolbar đặt dưới khung. Ngăn cuộn trang trong lúc người học đang vẽ trên canvas.

## 5. Áp dụng mã nguồn Wenbun

Wenbun có phần luyện viết và lịch ôn chạy phía client. Với dự án này chỉ tham khảo hoặc port các phần sau:

* Luồng chuyển giữa xem mẫu và tự viết.
* Cách điều phối nhiều ký tự trong một từ hoặc deck.
* Cách thu thập callback lỗi/hoàn thành từ Hanzi Writer.
* Cách tổ chức state phiên luyện ở client.

Không port trong PR-13:

* Svelte component và Tauri shell.
* FSRS, deck management, profile sync và tính năng ngoài luyện viết.
* Backend của Wenbun.

Nếu sao chép hoặc chỉnh sửa file mã nguồn từ Wenbun, phải giữ thông tin bản quyền, ghi chú file đã thay đổi và kèm giấy phép theo repository.

## 6. Triển khai Backend -- NestJS

Backend không xử lý nhận diện nét. Backend chỉ kiểm tra quyền, giới hạn lượt và lưu kết quả phiên.

| Method | Endpoint | Chức năng |
| :--- | :--- | :--- |
| POST | `/api/practice/hanzi-writing/start` | Tạo phiên và trả danh sách ký tự. |
| POST | `/api/practice/hanzi-writing/:attemptId/complete` | Lưu kết quả cuối phiên. |
| GET | `/api/practice/attempts/:id` | Xem lại kết quả của chính người học. |

Sử dụng lại bảng `practice_attempts`:

* `practiceType`: `HANZI_WRITING`.
* `questionData`: danh sách ký tự của phiên.
* `answerData`: ký tự đã hoàn thành và số lỗi từng chữ.
* `score`: số ký tự hoàn thành; không phải điểm thi.
* `durationSeconds`: tổng thời gian luyện.

Backend kiểm tra attempt thuộc người dùng, chưa hoàn thành và các ký tự gửi lên thuộc phiên đã tạo. Do việc nhận diện chạy ở thư viện client, kết quả này chỉ dùng cho theo dõi luyện tập, không dùng làm kết quả thi chính thức.
