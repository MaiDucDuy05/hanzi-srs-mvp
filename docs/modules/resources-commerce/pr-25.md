## 1. Yêu cầu nghiệp vụ

Form liên hệ để học viên đăng ký tư vấn học HSK/HSKK hoặc mua tài liệu. Admin quản lý các lead.

### 1.1. Luồng người dùng

1. Vào trang "Liên hệ" (từ menu footer hoặc landing page).
2. Điền form:
   - Họ tên (bắt buộc).
   - Số điện thoại (bắt buộc).
   - Email (optional).
   - Nhu cầu: Dropdown (Đăng ký học online, Mua tài liệu, Tư vấn khóa học, Khác).
   - Ghi chú (optional, max 500 ký tự).
3. Bấm "Gửi" → Thông báo "Chúng tôi sẽ liên hệ trong 24h".
4. Hệ thống gửi email thông báo cho Admin (qua Brevo).

### 1.2. Luồng Admin quản lý lead

1. Admin vào Dashboard → tab "Liên hệ".
2. Danh sách lead: Tên, SĐT, Nhu cầu, Ngày gửi, Trạng thái.
3. Admin click vào → xem chi tiết.
4. Đổi trạng thái: `Chưa xử lý` → `Đã liên hệ` → `Hoàn thành` / `Hủy`.
5. Thêm ghi chú nội bộ (chỉ Admin thấy).

### 1.3. Quy tắc chính

* Không cần đăng nhập để gửi form.
* Rate limit: Tối đa 3 lần gửi/IP/ngày (chống spam).
* Validation: SĐT phải đúng format Việt Nam (10 chữ số, bắt đầu 0).
* Email Admin nhận thông báo qua Brevo SMTP.
* Nếu user đã đăng nhập: Tự động điền tên + email.

## 2. Thiết kế dữ liệu

## 3. Triển khai Backend — NestJS

### 3.1. API cần triển khai

| Method | Endpoint | Actor | Chức năng |
| :--- | :--- | :--- | :--- |
| POST | `/api/contacts` | Public | Gửi form liên hệ |
| GET | `/api/admin/contacts` | Admin | Danh sách lead (filter, pagination) |
| GET | `/api/admin/contacts/:id` | Admin | Chi tiết lead |
| PUT | `/api/admin/contacts/:id/status` | Admin | Cập nhật trạng thái |
| PUT | `/api/admin/contacts/:id/notes` | Admin | Thêm ghi chú nội bộ |

### 3.2. Luồng xử lý submit

1. Validate input (tên, SĐT format, rate limit IP).
2. Lưu vào DB.
3. Gửi email thông báo cho Admin qua Brevo (async, không block response).
4. Trả response thành công.
