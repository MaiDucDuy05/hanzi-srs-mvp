## 1. Yêu cầu nghiệp vụ

AI phân tích dữ liệu học sinh (lịch sử làm bài, sổ lỗi sai) để gợi ý lộ trình ôn tập cá nhân hóa cho từng học sinh hoặc cả lớp.

### 1.1. Luồng chính

1. Giáo viên vào trang chi tiết học sinh hoặc tổng quan lớp.
2. Bấm nút "AI Gợi ý lộ trình".
3. Hệ thống tổng hợp dữ liệu:
   - Top 10 câu hỏi sai nhiều nhất.
   - Kỹ năng yếu nhất (dựa trên điểm từng loại bài).
   - Bài học nào chưa hoàn thành.
   - Xu hướng điểm (tăng/giảm/bình ổn).
4. Gửi dữ liệu tổng hợp tới AI, nhận phân tích và gợi ý.
5. Hiển thị kết quả:
   - **Phân tích điểm mạnh/yếu** (text ngắn).
   - **Lộ trình đề xuất** (danh sách 5-10 hoạt động theo thứ tự ưu tiên).
   - **Bài tập gợi ý** (link tới bài học/bài tập cụ thể trong hệ thống).

### 1.2. Phạm vi phân tích

| Đối tượng | Dữ liệu nguồn |
| :--- | :--- |
| Cá nhân học sinh | Lịch sử exam + practice attempts, sổ lỗi sai |
| Cả lớp | Aggregation tất cả học sinh, top câu sai chung |

### 1.3. Quy tắc chính

* Chỉ Teacher được sử dụng.
* Rate limit: 5 lần/ngày/giáo viên.
* Dữ liệu phân tích lấy từ 30 ngày gần nhất.
* Cần tối thiểu 3 bài kiểm tra đã chấm để phân tích có ý nghĩa.
* Không gửi dữ liệu cá nhân (tên, email) lên AI — chỉ gửi số liệu thống kê.

## 3. Triển khai Backend — NestJS

### 3.1. API cần triển khai

| Method | Endpoint | Actor | Chức năng |
| :--- | :--- | :--- | :--- |
| POST | `/api/ai/learning-path/student/:studentId` | Teacher | Gợi ý cho 1 học sinh |
| POST | `/api/ai/learning-path/classroom/:classroomId` | Teacher | Gợi ý cho cả lớp |
| GET | `/api/ai/learning-path/:id` | Teacher | Xem kết quả đã tạo |
| GET | `/api/ai/learning-path` | Teacher | Lịch sử gợi ý |

### 3.2. Luồng xử lý

1. Validate teacher sở hữu lớp/học sinh.
2. Aggregate dữ liệu từ `exam_attempts`, `practice_attempts`, `mistake_books`.
3. Xây dựng prompt tổng hợp (không chứa PII).
4. Gọi AI provider, parse response.
5. Map `recommended_activities` về entity thực trong hệ thống (lesson_id, practice_type).
6. Lưu kết quả, trả response.

### 3.3. Prompt mẫu

```text
Bạn là chuyên gia giáo dục tiếng Trung. Phân tích dữ liệu học tập sau và đề xuất lộ trình ôn tập:

Dữ liệu:
- Cấp HSK hiện tại: {level}
- Điểm trung bình: {avg_score}%
- Kỹ năng yếu nhất: {weakest_skill} ({score}%)
- Top 5 lỗi thường gặp: {errors}
- Xu hướng điểm: {trend}

Trả kết quả JSON:
{
  "analysis": "Phân tích ngắn gọn...",
  "strengths": ["..."],
  "weaknesses": ["..."],
  "recommended_activities": [
    { "priority": 1, "type": "lesson|practice|review", "description": "...", "reason": "..." }
  ]
}
```

## 5. Tiêu chí hoàn thành

PR-16 được nghiệm thu khi:

* Giáo viên tạo được gợi ý lộ trình cho cá nhân học sinh và cả lớp.
* Phân tích AI đưa ra điểm mạnh/yếu có ý nghĩa.
* Gợi ý hoạt động link được tới bài học/bài tập thực trong hệ thống.
* Rate limit 5 lần/ngày được enforce.
* Không gửi PII lên AI provider.
* Cần tối thiểu 3 bài kiểm tra đã chấm mới cho phép tạo gợi ý.
